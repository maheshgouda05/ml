Student Math Score Predictor

Project Description : This is a simple Machine Learning project that predicts a student's math score using their reading and writing scores.

Dataset
-Students Performance Dataset
-Features: Reading Score, Writing Score
-Target: Math Score

Steps Followed
-Loaded dataset
-Performed data visualization (EDA)
-Split data into training and testing
-Trained ML models:
-Decision Tree
-Random Forest
-Evaluated using R² score
-Saved final model using pickle

Model Used
-Random Forest Regressor (Final Model)

Result
-Model performance measured using R² score
-Random Forest performed better than Decision Tree

Tools Used
-Python
-Pandas
-Matplotlib
-Seaborn
-Scikit-learn

Output : Trained model saved as student_model.pkl

Goal : To predict math scores based on reading and writing performance.
